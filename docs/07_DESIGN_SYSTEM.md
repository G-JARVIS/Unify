# UI Token & Design System Standards

- **Primary Color**: `#6366F1` (Indigo / Purple accents as seen in prototype UI).
- **Background Theme**: Dark `#0B0F19` sidebar / Light `#F9FAFB` content area with glassmorphism overlays.
- **Typography**: Inter / Sans-serif clean enterprise hierarchy.
- **Badges**:
  - Match Score: Green (`#22C55E`) for >85% match.
  - Verification: Cyan (`#06B6D4`) with `ShieldCheck` icon.
  - Status: Colored rounded pills for `Shortlisted`, `Pending`, `Accepted`, `Rejected`.
